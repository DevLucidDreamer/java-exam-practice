# JAVA STUDY ROOM

자바 프로그래밍 1~5장 개념 중심 모의고사. 4회 × 20문제(객관식 18, 서술형 2)로 구성했습니다. 시험 후기를 참고해 직접 작성한 연습문제이며 실제 기출문제가 아닙니다. Java 10 강의 문법을 기준으로 합니다.

## 사용 기능

- 문항당 5점, 회차별 100점. 시간 제한 없이 소요 시간 측정·명시적 일시정지
- 답안 자동 저장 및 새로고침·브라우저 재시작 후 이어 풀기
- 서술형 결과 2점·이유 3점의 핵심어 기반 잠정 채점 및 모범답안 대조·수동 확정
- 회차별 기록, 장별 누적 정답률, 문제별 최근 오답만 재풀이
- 최근 200회 기록 저장, JSON 백업 및 다른 기기로 가져오기

서술형 자동 채점은 문맥·부정 표현·모든 동의어를 이해하지 못합니다. 반드시 모범답안을 보고 점수를 확정하세요. 만점 미만인 문항은 부분 정답도 오답 목록에 남습니다. 전체 시험 평균에는 오답 복습을 포함하지 않으며, 장별 누적 정답률에는 복습을 포함합니다.

## 개인정보·저장

계정·서버·분석 도구·외부 폰트·외부 자바스크립트 없이 동작합니다. 모든 학습 데이터는 `localStorage`의 `java-study-room.v1` 키에만 저장됩니다. 다른 브라우저/기기/원본 주소와 자동 동기화되지 않습니다. 시크릿 모드 종료, 사이트 데이터 삭제로 기록이 없어질 수 있으니 JSON 백업을 사용하세요. 공개 저장소에는 강의 PDF·시험 후기 이미지·개인 답안 파일을 포함하지 않습니다.

## 실행·검증

정적 서버로 이 폴더를 제공하면 됩니다. 빌드·패키지 설치가 필요하지 않습니다. `index.html`을 직접 여는 경우 브라우저에 따라 파일 주소 저장소 제약이 있을 수 있어 HTTP 서버를 권장합니다.

```text
python -m http.server 8765
node --test tests/core.test.js
```

GitHub Pages는 main 브랜치의 루트(`/`)를 배포 대상으로 사용합니다. 모든 자산은 상대경로라 프로젝트 하위 경로에서도 작동합니다.

## 문제 기준

1장 실행 원리·WORA·개발 환경, 2장 자료형·입력·연산·조건, 3장 반복·배열·예외, 4장 생성자·접근·참조 전달·static·final, 5장 상속·캐스팅·동적 바인딩·추상 클래스·인터페이스.

문항마다 강의 장·쪽수로 복습 위치를 표시합니다. 자료의 단순화·오타를 그대로 정답으로 만들지 않고 자바 언어 규칙에 맞게 보완했습니다. 예: 객체 인자도 참조 값의 복사, 객체 배열 생성과 원소 객체 생성의 구분, 인터페이스의 default 메소드 허용.
