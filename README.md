# JAVA STUDY ROOM - 2026.10.20 개정

시험 범위: **1~4장 전체 + 5장 p.1~29 (instanceof 예제까지)**. 5장 p.30 이후 내용은 새 학습·문제에서 제외했습니다.

- 전면 교체한 80문제: 4회 × 20문제(객관식 18 + 서술형 2), 회차별 100점
- 34개 개념: 핵심 설명·예제·쉬운 비유·단계별 해석·시험 판단 포인트·확인 질문
- 별도 신규 최종점검 PDF: 17문항(객관식 15 + 서술형 2), 100점
- 시험 후기의 WORA·예외 이름·생성자·접근 지정자·업캐스팅 비중을 높였으며 손코딩 없음
- PDF 40분·배점은 연습용 설정이며 실제 시험 공지로 확정된 정보가 아닙니다. 실제 기출 재현이 아닌 창작 문제입니다.

## 기록 보존

새 문제는 r2- 식별자를 사용합니다. 기존 문항은 legacy-questions.js에 기록 해석용으로만 남기며, 신규 회차·장별 확인·오답 풀기에서는 사용하지 않습니다. 이전 응시 기록은 조회·내보내기 가능하고 신규판 평균과 오답에는 합산하지 않습니다. 이전판 진행 중 답안은 java-study-room.v1.before-20261020 키로 최초 1회 원본을 백업하고 신규판 풀이를 시작합니다. 이전판 백업을 가져올 때 진행 중 답안은 재개하지 않습니다.

학습 데이터는 localStorage에만 저장하며 외부로 전송하지 않습니다. 최근 200회 기록, JSON 내보내기·가져오기, 타이머·일시정지, 오답 복습을 지원합니다. 서술형 핵심어 채점은 잠정 점수이며 모범답안과 비교해 수동 확정해야 합니다.

## 실행과 검증

운영 주소: https://java-exam-practice.pages.dev/ (Cloudflare Pages Direct Upload)

Cloudflare 로그인 후 PowerShell에서 `./deploy-cloudflare.ps1`을 실행하면 배포에 필요한 10개 파일만 dist에 모아 같은 프로젝트에 배포합니다. `-BuildOnly`는 업로드 없이 배포 파일만 준비합니다. GitHub 빌드를 거치지 않습니다. 인증 토큰은 저장소에 넣지 않습니다.

주소가 달라지면 localStorage도 분리됩니다. 기존 GitHub Pages의 기록은 해당 사이트에서 JSON으로 내보낸 뒤 새 주소의 학습 기록 화면에서 가져옵니다.

정적 서버로 폴더를 제공합니다. GitHub Pages main 브랜치의 루트에 배포합니다. 강의 PDF나 후기 이미지는 저장소에 올리지 않습니다. final-mock-exam.pdf는 직접 작성한 창작 문제지입니다.
